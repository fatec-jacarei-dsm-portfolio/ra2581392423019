Boitatá - HeatSentinel

Este projeto é uma aplicação web voltada para a gestão ambiental, inspirada no Programa Queimadas do INPE. Ele fornece informações sobre áreas queimadas, focos de calor e risco de fogo no Brasil, utilizando dados geoespaciais para visualizações interativas.

  • **Tecnologias Envolvidas**: React, Node.js, TypeScript, PostgreSQL, Recharts.
  • **Minhas Contribuições**: Desenvolvimento de componentes de visualização de dados, integração com APIs, tratamento de dados geoespaciais.
